> **Calculyra** is a modern, high-precision scientific calculator featuring full expression parsing, editable calculation history, and an integrated multi-unit converter.

---

## ✨ Key Features
- **Full Expression Evaluator:** Type complex mathematical expressions with brackets, exponents, and trigonometric functions with live result preview.
- **Persistent Calculation History:** Review previous calculations, insert past results into current formulas, and export logs.
- **Comprehensive Unit Converter:** Length, Area, Weight, Temperature, Data, Currency, and Time conversions.
- **Haptic Tactile Feedback & Fluent UI:** Minimalist distraction-free layout with smooth transitions and AMOLED dark mode.

---

## 🛠️ Tech Stack
- **Framework:** Flutter & Dart
- **Math Engine:** Recursive descent expression parser with arbitrary precision floating-point evaluation
- **Storage:** Local SQLite / Hive for instant offline history retrieval
